Sum of Two Numbers

You are given two integers a and b. Print their sum. The input contains a single line with two integers a and b separated by a space (0 <= a, b <= 1,000,000,000). The output must contain exactly one integer: the sum of a and b.

Example 1. Input: 3 4. Output: 7.

Example 2. Input: 0 0. Output: 0.

Example 3. Input: 1000000000 1000000000. Output: 2000000000.

Constraints. 0 <= a, b <= 10^9. Time limit: 1 second. The answer always fits in a 64-bit integer.
